1. INTRODUCTION                                           *agent-session-intro*

agent-session.nvim is a Neovim plugin for managing multiple AI agent sessions
(e.g., Claude CLI, custom LLM CLI tools) within floating or split windows.

==============================================================================
2. INSTALLATION                                    *agent-session-installation*

Using lazy.nvim: >lua
    {
      "yoch/agent-session.nvim",
      opts = {
        default_agent = "claude",
      },
      keys = {
        { "<leader>as", "<cmd>AgentSessionToggle<cr>", desc = "Toggle Agent Session" },
        { "<leader>an", "<cmd>AgentSessionNew<cr>", desc = "New Agent Session" },
        { "<leader>al", "<cmd>AgentSessionList<cr>", desc = "List Agent Sessions" },
      },
    }
<

==============================================================================
3. CONFIGURATION                                         *agent-session-config*

Default options: >lua
    require("agent-session").setup({
      session_dir = vim.fn.stdpath("data") .. "/agent-sessions",
      default_agent = "claude",
      agents = {
        claude = {
          cmd = "claude",
          args = {},
          env = {},
        },
      },
      ui = {
        position = "float", -- "float", "split", "vsplit"
        width = 0.85,
        height = 0.8,
        border = "rounded",
        title = " Agent Session ",
      },
    })
<

==============================================================================
4. COMMANDS                                           *agent-session-commands*

:AgentSession [toggle|new|list|delete|rename|prompt|send]
    Main command router to manage agent sessions.

:AgentSessionToggle
    Toggle the active agent session window.

:AgentSessionNew [name] [agent]
    Create and launch a new agent session.

:AgentSessionSelectAgent
    Open interactive picker to select agent CLI and launch.

:AgentSessionList
    Show session selector picker.

:AgentSessionSidebar / :AgentSessionTree
    Toggle the left sidebar session explorer.

:AgentSessionPrompt [target] [prompt]
    Send a prompt/command to a specific session (interactive picker if omitted).

:AgentSessionSendCommand [target] [prompt]
    Alias for `:AgentSessionPrompt`.

:AgentSessionRename [name] [target]
    Rename current session or specified session.

:AgentSessionDelete [target]
    Terminate and remove session.

:AgentSessionSendLine
    Send `@file:line` (or `@file:start-end`) to the active session.

:AgentSessionSendLineTo [target]
    Send `@file:line` (or `@file:start-end`) directly to a chosen target session.

:AgentSessionSendFile
    Send `@file` to the active session.

:AgentSessionSendFileTo [target]
    Send `@file` directly to a chosen target session.

==============================================================================
5. LUA API                                                 *agent-session-api*

require("agent-session").setup(opts)
    Initialize plugin with custom configuration.

require("agent-session").new_session(name, agent_name)
    Create a new agent session.

require("agent-session").toggle()
    Toggle current session window.

require("agent-session").list_sessions()
    Open session selector via `vim.ui.select`.

require("agent-session").prompt_session(target, text, opts)
    Send prompt / command to target session (or prompt interactively).

require("agent-session").send(text)
    Send text / prompt into current active session.

require("agent-session").rename_session(new_name, target)
    Rename session.

require("agent-session").delete_session(target)
    Close and delete an agent session.

require("agent-session").send_line_ref_to(target, line1, line2)
    Send line/selection reference to a chosen target session.

require("agent-session").send_file_ref_to(target)
    Send file reference to a chosen target session.
